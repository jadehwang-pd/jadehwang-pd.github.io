# Jade Hwang — Portfolio

## GitHub Pages 배포
1. GitHub에서 새 저장소 생성 (예: `jadehwang-pd.github.io` → 주소가 https://jadehwang-pd.github.io 가 됨)
2. 이 폴더 안의 **모든 파일**(index.html, assets/, ds/, support.js, image-slot.js, .nojekyll)을 저장소 루트에 업로드
   - 웹 업로드: Add file → Upload files → 폴더째 드래그
   - `.nojekyll`은 숨김 파일이라 드래그로 안 올라갈 수 있음 → Add file → Create new file → 이름 `.nojekyll`, 내용 비우고 Commit
3. Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)` → Save
4. 1–2분 후 주소 접속
